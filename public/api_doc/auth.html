POST /api/auth/login

Permite a los usuarios (pacientes o médicos) iniciar sesión en el sistema.

Parámetros de Entrada

Campo Tipo Requerido Descripción
email string Sí Email del usuario
password string Sí Contraseña del usuario

Ejemplo de Petición

POST /api/auth/login Content-Type: application/json { "email": "doctor@ejemplo.com", "password": "password123" }

Respuestas

200 Login exitoso
{ "message": "Login exitoso", "token": "1|abcd1234...", "user_type": "practitioner", "user": { "id": 1, "name": "Dr. Juan Pérez", "email": "doctor@ejemplo.com", "default_client_id": 1 }, "practitioner": { "id": 1, "name": "Dr. Juan Pérez", "phone": "+507 6000-0000", "birth_date": "1980-05-15", "gender": "male", "identifier": "8-123-456", "registry": "RM-12345", "active": true, "clients": [ { "id": 1, "name": "Clínica Ejemplo", "phone": "+507 200-0000", "address": "Ciudad de Panamá" } ], "clients_count": 1 } }
422 Datos de validación incorrectos
{ "message": "Las credenciales proporcionadas son incorrectas.", "errors": { "email": ["Las credenciales proporcionadas son incorrectas."] } }
POST /api/auth/register

Registra un nuevo paciente en el sistema.

Parámetros de Entrada

Campo Tipo Requerido Descripción
email string Sí Email del paciente (max: 255)
identifier string Sí Número de identificación
identifier_type string Sí Tipo de ID: CC, CE, PA, PT, SS
given_name string Sí Nombre(s) (max: 255)
family_name string Sí Apellido(s) (max: 255)
password string Sí Contraseña (mín: 8 caracteres)
password_confirmation string Sí Confirmación de contraseña
phone string Sí Número de teléfono (max: 20)
birth_date date Sí Fecha de nacimiento (YYYY-MM-DD)
gender string Sí Género: male, female, unknown
address string No Dirección del paciente

Ejemplo de Petición

POST /api/auth/register Content-Type: application/json { "email": "paciente@ejemplo.com", "identifier": "8-123-456", "identifier_type": "CC", "given_name": "María", "family_name": "González", "password": "password123", "password_confirmation": "password123", "phone": "+507 6000-1234", "birth_date": "1990-03-15", "gender": "female", "address": "Ciudad de Panamá" }

Respuestas

201 Registro exitoso
{ "message": "Registro exitoso", "token": "2|xyz789...", "user": { "id": 2, "name": "María González", "email": "paciente@ejemplo.com" }, "patient": { "id": 1, "name": "María González", "phone": "+507 6000-1234", "birth_date": "1990-03-15" } }
POST /api/auth/logout

Cierra la sesión del usuario actual y revoca el token de acceso.

Headers Requeridos

Authorization: Bearer {token}

Ejemplo de Petición

POST /api/auth/logout Authorization: Bearer 1|abcd1234...

Respuestas

200 Logout exitoso
{ "message": "Logout exitoso" }
POST /api/auth/refresh

Renueva el token de acceso del usuario actual.

Headers Requeridos

Authorization: Bearer {token}

Respuestas

200 Token renovado
{ "message": "Token renovado", "token": "3|newtoken123...", "user_type": "patient" }
GET /api/auth/user

Obtiene la información del usuario autenticado actual.

Headers Requeridos

Authorization: Bearer {token}

Respuestas

200 Información del usuario
{ "user_type": "patient", "user": { "id": 2, "name": "María González", "email": "paciente@ejemplo.com" }, "patient": { "id": 1, "name": "María González", "phone": "+507 6000-1234", "birth_date": "1990-03-15", "gender": "female", "identifier": "8-123-456", "identifier_type": "CC" } }
POST /api/auth/forgot-password

Envía un enlace de restablecimiento de contraseña al email del usuario.

Parámetros de Entrada

Campo Tipo Requerido Descripción
email string Sí Email del usuario

Respuestas

200 Enlace enviado
{ "message": "Se ha enviado un enlace de restablecimiento de contraseña a tu email." }
POST /api/auth/reset-password

Restablece la contraseña del usuario usando un token de reset.

Parámetros de Entrada

Campo Tipo Requerido Descripción
token string Sí Token de restablecimiento
email string Sí Email del usuario
password string Sí Nueva contraseña (mín: 8)
password_confirmation string Sí Confirmación de contraseña

Respuestas

200 Contraseña restablecida
{ "message": "Tu contraseña ha sido restablecida exitosamente." }
