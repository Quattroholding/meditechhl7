Sistema de Notificaciones: Meditec PTY incluye un sistema completo de notificaciones que mantiene informados a médicos, pacientes y administradores sobre eventos importantes del sistema, citas médicas, recordatorios y alertas.
GET /api/doctor-notifications/{doctor_id}

Obtiene las notificaciones específicas para un médico, incluyendo citas, recordatorios y alertas del sistema.

Headers Requeridos

Authorization: Bearer {token}

Parámetros de Ruta

Parámetro Tipo Descripción
doctor_id integer ID del médico para obtener sus notificaciones

Parámetros de Consulta

Parámetro Tipo Requerido Descripción
type string No Filtrar por tipo: appointment, reminder, system, alert
status string No Filtrar por estado: unread, read, archived
priority string No Filtrar por prioridad: low, medium, high, urgent
date_from date No Fecha desde (YYYY-MM-DD)
date_to date No Fecha hasta (YYYY-MM-DD)
limit integer No Número máximo de notificaciones (por defecto: 50)

Ejemplo de Petición

GET /api/doctor-notifications/1?type=appointment&status=unread&priority=high&limit=20 Authorization: Bearer 1|abcd1234...

GET /api/users

Obtiene notificaciones generales del sistema para usuarios (cuando se usa con contexto de notificaciones).

Headers Requeridos

Authorization: Bearer {token}

Parámetros de Consulta

Parámetro Tipo Requerido Descripción
notifications boolean Sí Debe ser true para obtener notificaciones
user_type string No Filtrar por tipo: patient, practitioner, admin
global_only boolean No Solo notificaciones globales (por defecto: false)

Ejemplo de Petición

GET /api/users?notifications=true&user_type=patient Authorization: Bearer 1|abcd1234...

Tipos de Notificaciones

El sistema maneja diferentes tipos de notificaciones según su propósito:

Tipos Disponibles:

  • appointment Citas: Notificaciones relacionadas con citas médicas (nuevas, cambios, cancelaciones)
  • reminder Recordatorios: Recordatorios automáticos de citas próximas o tareas pendientes
  • system Sistema: Notificaciones del sistema (actualizaciones, mantenimiento, cambios)
  • alert Alertas: Notificaciones urgentes o importantes que requieren atención inmediata

Estados de Notificaciones

Las notificaciones pueden tener los siguientes estados:

Estado Descripción Acción Requerida
unread Notificación no leída por el usuario Marcar como leída
read Notificación leída por el usuario Opcional: archivar
archived Notificación archivada (oculta de la vista principal) Puede ser restaurada
Importante: Las notificaciones de alta prioridad y urgentes deben ser atendidas promptamente para garantizar la continuidad del servicio médico y la satisfacción del paciente.

Funcionalidades Adicionales:

  • Notificaciones Push: Integración con servicios de notificaciones móviles
  • Email: Notificaciones importantes también se envían por correo electrónico
  • SMS: Recordatorios de citas pueden enviarse por mensaje de texto
  • Tiempo Real: Las notificaciones se actualizan en tiempo real usando WebSockets
  • Programación: Notificaciones pueden ser programadas para envío futuro
