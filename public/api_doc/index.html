Bienvenido a la API de Meditec PTY

Esta documentación proporciona información completa sobre todos los endpoints disponibles en la API de Meditec PTY, un sistema completo de gestión médica multi-tenant.

Características principales:

  • Sistema multi-tenant con aislamiento de datos por cliente
  • Autenticación basada en tokens Sanctum y API Tokens
  • Gestión completa de pacientes y médicos
  • Sistema de citas médicas
  • Cumplimiento con estándares FHIR
  • Soporte para múltiples roles: pacientes, médicos, asistentes y administradores
  • API v1 con tokens para integración externa

URLs Base:

https://meditecpty.com/api      (Sanctum Auth)
https://meditecpty.com/api/v1   (API Token Auth)

Autenticación:

Para usuarios autenticados (Sanctum):

Authorization: Bearer {sanctum-token}

Para integraciones externas (API v1):

Authorization: Bearer {api-token}

Los tokens API incluyen restricciones por IP y scopes para mayor seguridad.
