PUT /api/patient/personal-data

Actualiza los datos personales del paciente autenticado.

Headers Requeridos

Authorization: Bearer {token} Content-Type: application/json

Parámetros de Entrada

Campo Tipo Requerido Descripción
given_name string Sí Nombre(s) del paciente (máx: 255)
family_name string Sí Apellido(s) del paciente (máx: 255)
identifier_type string Sí Tipo de identificación: CC, CE, PA, SS, PT
identifier string Sí Número de identificación (formato según tipo)
gender string Sí Género: male, female, other
birth_date date Sí Fecha de nacimiento (YYYY-MM-DD, antes de hoy)
phone string Sí Número de teléfono (máx: 20)
address string No Dirección del paciente (máx: 500)
marital_status string No Estado civil: soltero, casado, divorciado, viudo, separado, unido
blood_type string No Tipo de sangre: A+, A-, B+, B-, AB+, AB-, O+, O-
Formatos de Identificación:
  • CC (Cédula): 8-123-456
  • CE (Cédula Extranjera): PE-123-456
  • PA (Pasaporte): N1234567
  • PT (Permiso Temporal): Formato alfanumérico
  • SS (Seguro Social): 123-45-6789

Ejemplo de Petición

PUT /api/patient/personal-data Authorization: Bearer 1|abcd1234... Content-Type: application/json { "given_name": "María Alejandra", "family_name": "González Pérez", "identifier_type": "CC", "identifier": "8-123-456", "gender": "female", "birth_date": "1990-03-15", "phone": "+507 6000-1234", "address": "Calle Principal #123, Ciudad de Panamá", "marital_status": "soltera", "blood_type": "O+" }

Respuestas

200 Datos actualizados exitosamente
{ "message": "Datos personales actualizados exitosamente" }
422 Error de validación
{ "message": "Validation failed", "errors": { "identifier": ["El numero de identificacion debe ser el correcto."], "birth_date": ["La fecha de nacimiento debe ser anterior a hoy."] } }
PUT /api/patient/credentials

Actualiza las credenciales de acceso (email y contraseña) del paciente.

Headers Requeridos

Authorization: Bearer {token} Content-Type: application/json

Parámetros de Entrada

Campo Tipo Requerido Descripción
email string No Nuevo email del paciente
current_password string No* Contraseña actual (requerida si se cambia contraseña)
password string No Nueva contraseña (mín: 8 caracteres)
password_confirmation string No* Confirmación de nueva contraseña (requerida si se cambia contraseña)

Ejemplo de Petición

PUT /api/patient/credentials Authorization: Bearer 1|abcd1234... Content-Type: application/json { "email": "nuevo_email@ejemplo.com", "current_password": "password_actual123", "password": "nueva_password123", "password_confirmation": "nueva_password123" }

Respuestas

200 Credenciales actualizadas
{ "message": "Credenciales actualizadas exitosamente" }

GET /api/patient/medical-history/{section}

Obtiene una sección específica del historial médico.

Parámetros de Ruta

Parámetro Valores Posibles Descripción
section allergies, medications, conditions, procedures Sección del historial médico a obtener

Ejemplo de Petición

GET /api/patient/medical-history/allergies Authorization: Bearer 1|abcd1234...

Respuestas

200 Sección del historial obtenida
{ "data": { "allergies": [ { "id": 1, "substance": "Penicilina", "reaction": "Erupciones cutáneas", "severity": "moderate", "notes": "Desarrollado en la infancia" } ] } }
GET /api/patients

Lista todos los pacientes del sistema. Endpoint administrativo.

Acceso Restringido: Este endpoint está disponible solo para usuarios con permisos administrativos.

Headers Requeridos

Authorization: Bearer {admin-token}

Parámetros de Consulta

Parámetro Tipo Descripción
search string Buscar por nombre o identificación
page integer Número de página
per_page integer Elementos por página

Respuestas

200 Lista de pacientes
{ "data": [ { "id": 1, "name": "María González", "identifier": "8-123-456", "email": "maria@ejemplo.com", "phone": "+507 6000-1234", "age": 34, "last_appointment": "2024-01-15T10:00:00Z" } ], "pagination": { "current_page": 1, "total": 150, "per_page": 10 } }
