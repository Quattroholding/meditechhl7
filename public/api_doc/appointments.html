Nota: Todos los endpoints de citas requieren autenticación mediante token Bearer. Los pacientes solo pueden ver y gestionar sus propias citas, mientras que los médicos pueden gestionar citas asignadas a ellos.
GET /api/appointments

Obtiene la lista de citas del paciente autenticado con paginación y filtros opcionales.

Headers Requeridos

Authorization: Bearer {token}

Parámetros de Consulta (Query Parameters)

Parámetro Tipo Requerido Descripción
page integer No Número de página (por defecto: 1)
per_page integer No Elementos por página (1-100, por defecto: 10)
status string No Filtrar por estado: proposed, booked, checked-in , arrived, fulfilled , cancelled , noshow, entered-in-error
date_from date No Fecha desde (YYYY-MM-DD)
date_to date No Fecha hasta (YYYY-MM-DD)

Ejemplo de Petición

GET /api/appointments?page=1&per_page=5&status=booked&date_from=2024-01-01 Authorization: Bearer 1|abcd1234...

Respuestas

200 Lista de citas obtenida exitosamente
{ "data": [ { "id": 1, "status": "scheduled", "description": "Consulta general", "start": "2024-02-15 10:00:00", "end": "2024-02-15 10:30:00", "formatted_date": "15 de febrero, 2024", "formatted_time": "10:00 AM - 10:30 AM", "minutes_duration": 30, "practitioner": { "id": 1, "name": "Dr. Juan Pérez", "speciality": "Medicina Interna" }, "consulting_room": { "id": 1, "name": "Consultorio 101" }, "can_cancel": true, "can_reschedule": true } ], "pagination": { "current_page": 1, "per_page": 5, "total": 25, "last_page": 5, "from": 1, "to": 5, "has_more_pages": true } }
401 Usuario no autenticado
{ "message": "Usuario no autenticado" }
404 Paciente no encontrado
{ "message": "Paciente no encontrado" }
POST /api/appointments

Crea una nueva cita médica para el paciente autenticado.

Headers Requeridos

Authorization: Bearer {token} Content-Type: application/json

Parámetros de Entrada

Campo Tipo Requerido Descripción
practitioner_id integer Sí ID del médico
consulting_room_id integer No ID del consultorio
start datetime Sí Fecha y hora de inicio (YYYY-MM-DD HH:mm:ss)
duration integer No Duración en minutos (por defecto: 30)
description string No Descripción de la cita
reason string No Motivo de la cita

Ejemplo de Petición

POST /api/appointments Authorization: Bearer 1|abcd1234... Content-Type: application/json { "practitioner_id": 1, "consulting_room_id": 1, "start": "2024-02-15 10:00:00", "duration": 30, "description": "Consulta general", "reason": "Revisión médica anual" }

Respuestas

201 Cita creada exitosamente
{ "message": "Cita creada exitosamente", "appointment": { "id": 2, "status": "scheduled", "description": "Consulta general", "start": "2024-02-15 10:00:00", "end": "2024-02-15 10:30:00", "practitioner": { "id": 1, "name": "Dr. Juan Pérez" }, "consulting_room": { "id": 1, "name": "Consultorio 101" } } }
422 Error de validación
{ "message": "Los datos proporcionados no son válidos.", "errors": { "practitioner_id": ["El médico seleccionado es requerido"], "start": ["La fecha de inicio debe ser futura"] } }
GET /api/appointments/{id}

Obtiene los detalles de una cita específica.

Headers Requeridos

Authorization: Bearer {token}

Parámetros de Ruta

Parámetro Tipo Descripción
id integer ID de la cita

Respuestas

200 Detalles de la cita
{ "id": 1, "status": "scheduled", "description": "Consulta general", "start": "2024-02-15 10:00:00", "end": "2024-02-15 10:30:00", "reason": "Revisión médica anual", "practitioner": { "id": 1, "name": "Dr. Juan Pérez", "speciality": "Medicina Interna", "registry": "RM-12345" }, "consulting_room": { "id": 1, "name": "Consultorio 101", "location": "Primer piso" }, "patient": { "id": 1, "name": "María González" } }
PUT /api/appointments/{id}

Actualiza una cita existente (reprogramación).

Importante: Solo se pueden actualizar citas que estén en estado 'scheduled' y que no hayan pasado su fecha límite de cancelación.

Headers Requeridos

Authorization: Bearer {token} Content-Type: application/json

Parámetros de Entrada

Campo Tipo Requerido Descripción
start datetime No Nueva fecha y hora de inicio
duration integer No Nueva duración en minutos
description string No Nueva descripción

Respuestas

200 Cita actualizada exitosamente
{ "message": "Cita actualizada exitosamente", "appointment": { "id": 1, "status": "scheduled", "start": "2024-02-16 14:00:00", "end": "2024-02-16 14:30:00" } }
DELETE /api/appointments/{id}

Cancela una cita médica.

Headers Requeridos

Authorization: Bearer {token}

Respuestas

200 Cita cancelada exitosamente
{ "message": "Cita cancelada exitosamente" }
403 No se puede cancelar la cita
{ "message": "No se puede cancelar esta cita" }
GET /api/appointments/{id}/availability

Obtiene la disponibilidad de horarios para reprogramar una cita.

Headers Requeridos

Authorization: Bearer {token}

Parámetros de Consulta

Parámetro Tipo Requerido Descripción
date date No Fecha para consultar disponibilidad (YYYY-MM-DD)
days integer No Días a futuro para mostrar (por defecto: 7)

Respuestas

200 Disponibilidad obtenida
{ "availability": [ { "date": "2024-02-16", "day_name": "Viernes", "slots": [ { "time": "09:00", "available": true }, { "time": "09:30", "available": true }, { "time": "10:00", "available": false } ] } ] }
